# Кейс 5 Генерация страницы об организации

## Запуск

Требуется Node.js 18 или новее. В папке `case5_web` выполните:

```powershell
node generate.js
```

Откройте `output/index.html` в браузере. Генератор создаёт каталог `output` при необходимости и перезаписывает в нём `index.html` и `styles.css`. Интернет для просмотра не требуется; ссылка на официальный сайт откроется при наличии соединения.

## Устройство

`generate.js` содержит сведения об организации, список пяти вариантов и формирует UTF-8 HTML и CSS. Данные выводятся с HTML-экранированием. Адаптивные CSS-правила рассчитаны на узкий экран. Страница содержит пять примеров: Arial, Georgia, Verdana, Times New Roman, Courier New. Шрифтовые файлы не распространяются: браузер использует локально установленные шрифты либо запасные семейства CSS, поэтому на разных устройствах примеры могут выглядеть одинаково или иначе.

## Источники и ограничение шрифта

- [Сайт Lamoda Tech](https://latech.ru/) — описание цифровых продуктов и направлений команды; дата обращения 17.11.2026.
- Полное и краткое наименование и организационно-правовая форма приведены в исходном ТЗ для практики.
- Фирменный шрифт Lamoda Tech по доступным публичным сведениям не установлен. В качестве основного использован системный стек `system-ui, -apple-system, "Segoe UI", sans-serif`; это учебное допущение, а не заявление о фирменной гарнитуре. Прямой просмотр CSS сайта из среды выполнения заблокирован сетевыми ограничениями; его следует проверить при наличии доступа или уточнить у организации. Пять дополнительных семейств — только примеры для сравнения, не утверждение об использовании их организацией.
